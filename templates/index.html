API Reference

Every endpoint this backend exposes.

Open Swagger UI ↗

Authentication

POST/api/auth/register/Create a new account
POST/api/auth/login/Log in, receive JWT tokens
POST/api/auth/refresh/Refresh an access token

Patients

GET/api/patients/List your patients
POST/api/patients/Add a patient
GET/api/patients/<id>/Patient details
PUT/api/patients/<id>/Update a patient
DELETE/api/patients/<id>/Remove a patient

Doctors & Assignments

GET/api/doctors/List all doctors
POST/api/doctors/Add a doctor
GET/api/mappings/List assignments
POST/api/mappings/Assign a doctor to a patient
GET/api/mappings/<patient_id>/Doctors for one patient
DELETE/api/mappings/<id>/Remove an assignment
